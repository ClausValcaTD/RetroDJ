# RetroDJ (RDJ)

[![Build Status](https://github.com/RetroDJ/RetroDJ/actions/workflows/build.yml/badge.svg)](https://github.com/RetroDJ/RetroDJ/actions/workflows/build.yml)
![Genesis ROM](https://img.shields.io/badge/Genesis%20ROM-passing-brightgreen)

GPLv3 Open Source Chiptune Tracker controlling retro hardware sound chips directly via register writes.
No sample playback. No ROMs. Pure register control = authentic chip sound on real hardware AND emulators.
